# Random Picker

Simple Android app that picks a random item from your own lists.

- Multiple named lists, saved on the phone
- No-repeat mode (picked items are crossed out; tap **Reset** to restore)
- Spin animation before the result
- English / Arabic (follows phone language), light / dark theme

## Get the APK
Open the **Releases** page → *Random Picker (latest build)* → download `RandomPicker.apk`.
Every push to `main` rebuilds it automatically (GitHub Actions).
